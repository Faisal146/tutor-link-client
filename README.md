# TutorLink Frontend

# Live Link - https://tutor-link-tawny.vercel.app/tutor/

## 🎓 Find & Connect with the Best Tutors

TutorLink is a platform that helps students discover tutors, book sessions, and manage their learning journey. This repository contains the frontend of the project, built with Next.js 15, TypeScript, and Tailwind CSS.

## 🚀 Features

### Public Pages

- **Home Page:** Search for tutors, view testimonials, and sign up.
- **Browse Tutors:** Filter tutors by subject, rating, price, and availability.
- **Tutor Profile:** View tutor details, rates, reviews, and booking calendar.
- **About Us:** Learn about the mission, team, and platform goals.
- **FAQ:** Common questions about tutoring, payments, and accounts.
- **Blog:** Educational resources, platform updates, and industry news.

### Private Pages

- **Student Dashboard:** Manage profile, bookings, payment history, and reviews.
- **Tutor Dashboard:** Manage profile, bookings, subjects, availability, and earnings.
- **Checkout Page:** Secure payments for tutor bookings.

## 🛠 Tech Stack

- **Framework:** Next.js 15 (SSR/SSG for SEO-friendly pages)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Context / Zustand (if applicable)
- **Authentication:** JWT-based authentication
- **Payment Integration:** SSLCommerz

## 🔧 Installation & Setup

### Prerequisites

- Node.js >= 18.x
- npm or yarn

### Steps

1. Clone the repository:
   ```sh
   git clone https://github.com/Faisal146/tutor-link-client
   cd tutorlink-frontend
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Set up environment variables:
   Create a `.env.local` file and add necessary API keys and backend URLs.
4. Start the development server:
   ```sh
   npm run dev
   ```

## 🚀 Deployment

For production build and deployment:

```sh
npm run build
npm start
```
